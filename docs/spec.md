# AI Usage — 1차 스펙 (초안)

> 2026-11-20 인터뷰 결과를 정리한 문서. 원본 앱 분석은 [`docs/analysis/claude-usage-tracker-rea.md`](analysis/claude-usage-tracker-rea.md)에 있다.

## 1. 한 줄 요약

여러 Claude 계정과 Codex의 사용 한도를 메뉴바에 동시에 띄우고, 사용 기록·실제 토큰·비용을 그래프로 보여 주는 macOS 메뉴바 앱. Rust(Tauri)와 React로 만든다.

## 2. 범위

### 포함

| 영역 | 내용 |
|---|---|
| 추적 대상 | Claude 구독 한도(여러 계정), OpenAI Codex, Claude API(Console) 비용, Claude Code 실제 토큰·비용, **브랜드별 누적 토큰 합계(Claude 전체·Codex 전체)** |
| 메뉴바 | 계정별 미니 막대 또는 숫자(설정에서 전환), 주간 사용률과 시간 눈금 |
| 팝오버 | 계정 카드 목록과 하단 요약 |
| 히스토리 창 | 그래프 4종 |
| 알림 | 서비스 장애, 로그인 만료, 한도 알림(설정한 만큼 썼을 때와 그 한도가 리셋됐을 때, 끌 수 있음) |
| 시작 | 로그인할 때 자동으로 열기 (설치한 앱에서 처음 켤 때 켜짐, 설정에서 끔) |
| 업데이트 | 새 버전 알림과 다운로드 페이지 열기 |

### 제외 (나중 후보)

- 바탕화면 위젯
- 앱에서 Claude Code 로그인 계정 바꾸기
- 세션 자동 시작, Keep Awake, 노치 표시
- 전역 단축키, 우클릭 메뉴, 데이터 내보내기
- 페이스 알림 (빨리 쓰고 있다는 알림. 카드의 예측 줄과 빨강 표시로 대신한다)
- 원본의 하트비트·스폰서 같은 외부 전송 일체

## 3. 데이터 소스

| 대상 | 방식 | 인증 정보 저장 | 갱신 |
|---|---|---|---|
| Claude 구독 (계정 N개) | 계정마다 앱 안에서 claude.ai에 로그인한다. 계정별로 WebKit 데이터 저장소를 분리한다. 요청은 그 계정의 숨은 웹뷰 안에서 `fetch`로 보낸다(Cloudflare 대응). `/api/organizations/{orgId}/usage`, Extra usage와 크레딧 관련 엔드포인트를 쓴다 | 계정별 WebKit 쿠키 저장소 | 1분 |
| Codex | `~/.codex/auth.json`을 읽기 전용으로 쓰고 `chatgpt.com/backend-api/wham/usage`를 조회한다. 토큰이 만료되면 `~/.codex/sessions` 로그의 `rate_limits`로 대체한다 | 앱에 저장하지 않음 | 1분 |
| Claude API 비용 | **계정마다** Admin API 키를 넣는다(계정마다 Console 조직이 다를 수 있음). 공식 Usage and Cost Analytics API(`/v1/organizations/analytics/cost`)로 이번 달 비용을 받아 그 계정 카드에 보여 준다. 데이터는 보통 몇 시간 늦다 | 키체인 (계정마다 `admin-api-key:<계정 ID>`) | 1시간 |
| Claude Code 토큰·비용 | `~/.claude/projects/**/*.jsonl`을 증분 파싱하고, 가격표로 비용을 추정한다. Orca 프로필들이 로그 폴더를 공유해서 계정별로는 나눌 수 없고 이 Mac 전체 합계다 | 없음 | 5분 (팝오버를 열면 즉시) |
| 브랜드별 누적 토큰 | Claude: 위 Claude Code 로그. Codex: `~/.codex/sessions/**/*.jsonl` 의 `token_count`(`total_token_usage`). 날마다 집계해 앱 DB 에 **영구 저장**한다. Claude Code 는 기본 30일 지난 로그를 지우므로, 앱이 따로 남겨야 누적이 유지된다 | 없음 | 5분 |
| 서비스 상태 | `status.claude.com`, `status.openai.com`의 Statuspage JSON | 없음 | 5분 |

**원칙**
- Claude Code의 로그인 정보(키체인)는 읽지도 쓰지도 않는다.
- 비밀값은 평문 파일에 절대 쓰지 않는다.

## 4. 메뉴바

- 메뉴바 항목 하나에 모든 계정(Claude N개, Codex)을 같은 모양으로 그린다. 순서는 설정 순서를 따르고, 클릭하면 팝오버가 열린다.
- 표시 스타일 (설정에서 전환)
  - **미니 막대 (기본):** `J ▕▓▓▓▓▓░░┃░░▏`
    - ▓ = 남은 사용량 (사용한 양 모드에서는 사용량)
    - ┃ = 남은 시간 (사용한 양 모드에서는 지난 시간)
    - 남은 양이 남은 시간보다 짧으면 정해진 속도보다 빨리 쓰고 있다는 뜻이다.
  - **숫자:** `J 58%`
- 지표는 주간 사용률이다. Codex도 주간 창 기준이다.
- 색은 평소에 단색(메뉴바 글자색, 다크 모드 자동)이다. 사용량이 시간 진행보다 **5%p 이상 앞서면**(= 남은 양이 남은 시간보다 5%p 이상 적으면) **빨강**으로 바뀐다. 예를 들어 시간이 30% 지났는데 36% 썼으면 빨강이다. 주황은 쓰지 않는다.
- **표시 기준은 남은 양이 기본**이다(2026-11-20 변경). 숫자와 막대가 모두 남은 사용량을 보여 주고, 세로 눈금은 남은 시간을 가리킨다. 설정에서 '사용한 양'으로 바꿀 수 있다.
- 계정 라벨은 계정마다 짧은 별칭, 이모지, 색 점 중에서 고른다. 전체 이름(예: 개인, 회사)은 사용자가 직접 붙인다.

## 5. 팝오버 (계정 카드)

```
┌ AI Usage ─────────────────── ⟳ ⚙ ┐
│ ● 개인 (J)                  Ultra │
│ 주간 ━━━━━━━━━━│────    58%      │
│      리셋 11월 24일 (월) 오후 11:00 │
│ 세션 ━━│────────────    12%      │  ← 5시간 한도가 있는 플랜만
│ ▸ 모델별 한도   ▸ Extra usage      │
│ ⌇ 최근 추세 (미니 차트)              │
├──────────────────────────────────┤
│ ◆ Codex (Cx)                 Pro  │
│ 주간 ━━━━━━━━━━━│───    55%      │
├──────────────────────────────────┤
│ Claude Code 오늘  1.2M 토큰 · $12.40 │
│ API 이번 달       $3.10            │
│ ● Claude 정상   ● OpenAI 정상        │
│ 1분 전 갱신 ⟳   히스토리 ↗   종료     │
└──────────────────────────────────┘
```

- 카드 안
  - 이름과 플랜
  - 주간 막대(시간 눈금 포함)와 리셋 시각
  - 5시간 세션 (있을 때만)
  - 모델별 한도 (접어서 표시)
  - Extra usage·크레딧 (있을 때만)
  - 미니 추세 차트
- Codex 카드도 같은 모양이다.
- 하단: **Claude 누적 토큰 · Codex 누적 토큰**(캐시 포함 합계, 입력·출력·캐시 내역은 펼쳐서), 이번 달 API 비용, 서비스 상태, 마지막 갱신 시각과 새로고침, 히스토리 창 열기, 설정, 종료
- 팝오버 바깥을 클릭하면 닫힌다.

## 6. 히스토리 창

| 그래프 | 내용 | 데이터 |
|---|---|---|
| 사용률 추이 | 계정별 주간·세션 사용률 선 그래프. 리셋 지점 표시 | 앱 기록 |
| 주간 사이클 비교 | 이번 주 소진 곡선을 지난 주들과 경과 시간 기준으로 겹쳐 비교 | 앱 기록 |
| 토큰·비용 (일별) | 일별 막대. 모델별, 프로젝트별, 세션별, 토큰 종류별(입력·출력·캐시)로 나눠 보기. API 실제 비용 함께 표시 | 로컬 로그, Admin API |
| 사용 패턴 히트맵 | 요일 × 시간대별 토큰 사용량 | 로컬 로그 |

창 위쪽의 기간 선택으로 그래프가 보여 줄 시간 범위를 고른다.

- 이번 주기: 이번 주 리셋 시각부터 지금까지
- 7일 / 30일: 최근 7일 또는 30일
- 전체: 기록된 모든 기간

## 7. 기록 저장

- SQLite 파일: `~/Library/Application Support/AI Usage/usage.db`
- 사용률은 값이 바뀔 때와 리셋 때만 기록하고 영구 보관한다. 원본처럼 개수 상한을 두고 지우지 않는다.
- 시간은 UTC ISO8601로 저장한다.
- 로컬 로그는 파일마다 마지막으로 읽은 위치를 기억해 두고 새 줄만 파싱한다.

## 8. 알림

- 서비스 장애: Claude 또는 OpenAI 상태 페이지에 장애가 올라올 때

## 13. 구현 순서

진행 상황 (2026-11-21): M1 ~ M4 완료. 다음은 M5, M6.

1. **M1 뼈대:** Tauri 프로젝트, 메뉴바 아이콘(가짜 데이터로 두 스타일), 팝오버 창
2. **M2 계정 연동:** Claude 계정 추가와 로그인 창, 계정별 사용량 조회, Codex(CLI 로그인 읽기), 메뉴바·팝오버에 실제 데이터 표시
3. **M2.5 브랜드별 누적 토큰:** 앱 DB(SQLite) 기반, Claude Code·Codex 로그 집계, 날마다 영구 저장, 팝오버 하단 표시
4. **M3 나머지 소스:** API 비용, 서비스 상태
5. **M4 기록과 히스토리 창:** SQLite 저장, 사용률 추이, 주간 사이클 비교
6. **M5 토큰 그래프:** 로그 집계, 토큰·비용 그래프, 히트맵
7. **M6 마무리:** 알림, 업데이트 확인, 한·영 번역, 릴리스 빌드(GitHub Actions)

## 14. 위험 요소와 대응

- claude.ai 내부 API는 비공식이라 바뀌면 깨질 수 있다. 응답 파싱을 한 곳에 모아서 고치기 쉽게 만든다.
- 앱 안 로그인 창에서 구글 로그인이 막힐 수 있다. 막히면 이메일 로그인을 안내하고, 세션 키를 직접 붙여넣는 방법을 대안으로 둔다.
- 계정별 로그인 저장소 분리는 Tauri의 `profile_identifier`(macOS 14 이상)로 공식 지원된다. 2026-11-20에 Tauri 소스로 확인했다.
- ad-hoc 서명이라 업데이트 후 키체인에 저장한 Admin API 키에 접근할 때 허용을 다시 물을 수 있다.
- 평소 브라우저의 로그인(쿠키 읽기, 확장)은 쓰지 않는다. 브라우저 프로필 하나에 계정 하나만 되고, 브라우저에서 계정을 바꾸면 앱에서도 끊기기 때문이다.

## 15. 확정된 세부 값

- 로그인: 앱 안 로그인 창 (계정별 저장소 분리)
- 빨강 기준: 사용량이 시간 진행보다 5%p 이상 앞설 때
- 갱신 주기: 구독 사용량 1분, Claude Code 로그 5분(팝오버를 열면 즉시), 서비스 상태 5분, API 비용 1시간
- 히스토리 기간: 이번 주기 / 7일 / 30일 / 전체
- Codex 토큰이 만료되면 세션 로그로 대체한다
- 브랜드별 토큰 합계: 기간은 **누적**만, **캐시 포함** 합계, 위치는 **팝오버 하단**, M2 확인 직후 바로 구현 (2026-11-20 결정)
- 'Claude 전체' 토큰은 이 Mac 의 Claude Code 사용량이다. claude.ai 웹·앱 채팅의 토큰 수는 어디서도 제공되지 않아 포함하지 못한다
- 한도 알림: 넣는다. 처음에는 뺐지만 사용자 후기 조사에서 가장 많이 칭찬받는 기능 중 하나였다. 주간·5시간 한도를 설정한 만큼(기본 90% 사용 = 10% 남음, 80·90·95 중 선택, 끔 가능) 쓰면 주기마다 한 번 알리고, 그렇게 알린 한도가 리셋되면 한 번 더 알린다 (2026-11-21 결정)
- 소진 예측: 카드의 한도 아래에 한 줄. 이 주기의 평균 속도로 리셋보다 창 길이의 2% 넘게 일찍 바닥날 때만 "이 속도면 월요일 오전 1시쯤 소진 예정"처럼 띄운다(추정이라 정시로 맞추고 오늘·내일·요일로 적음). 여유가 있으면 아무것도 띄우지 않고, 주기가 3% 지나기 전에는 예측하지 않는다. 하루 몫·오늘 쓴 양 문구는 어색해서 뺐다 (2026-11-21 결정)
- API 환산 금액: 누적 토큰에 모델별 API 표준 가격을 곱한 추정. 이번 달과 누적을 토큰 내역에 보여 준다. 캐시 쓰기는 5분·1시간 요금을 나눠 계산하고(예전 기록은 1시간으로 봄), 가격표(`pricing.rs`)에 없는 모델은 빼고 뺀 토큰 수를 알린다 (2026-11-21 결정)
- 화면 알림 방식: 팝오버가 보일 때만 갱신 이벤트를 보낸다(잠든 웹뷰를 깨우면 쉬는 동안 CPU 를 쓴다). 팝오버는 열릴 때, 히스토리 창은 보이는 동안 1분마다 직접 받아 간다
- 그래프는 표시 기준과 상관없이 쓴 양(누적)으로 그린다. 카드 그래프는 최근 7일 고정 축
- Claude API 비용은 계정에 묶는다: 키 입력은 계정 편집 화면, 비용은 그 계정 카드 안 (2026-11-21 결정)
- 로그인할 때 자동으로 열기: 넣는다. 설치한 앱을 처음 켤 때 켜 두고 설정에서 끌 수 있다 (2026-11-21 결정)
- 플랜 이름: 2026-10-30 이름 변경을 따른다 (Max 20x → Ultra, Max 5x → Max). API 의 내부 등급 코드는 예전 그대로라 앱이 바꿔 보여 준다
- 계정 색: 색각 이상에서도 구분되도록 검사한 8색 팔레트. 새 계정에는 이미 쓰는 색과 비슷하지 않은 색을 준다
- 주기(사이클) 나누기: 기록에 남은 리셋 시각을 기준으로 하고, 리셋 시각이 없는 예전 기록은 큰 폭 하락(10%p 초과)을 7일 간격에 맞춰 쓴다
